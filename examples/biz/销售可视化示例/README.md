# 示例：商业分析 · 数据可视化（biz）

- **场景**：`biz`
- **任务**：分析上半年销售额并生成可视化图表
- **验收要素（verify_markers）**：图表/可视化 · 趋势/增长 · 数据/销售额

## 这个示例展示什么

`销售分析.md` 是 biz 场景 mock 引擎产出的分析报告，覆盖「数据 → 趋势 → 图表」
三段，结构化验收判定 `passed=True`。图表以占位描述呈现（mock 环境下不生成真实图片）。

## 用户排除要素时（诚实省略）

若用户任务写成「分析上半年销售额，不用画图，给趋势和数据就行」，
强排除信号「不用」只作用到「画图」所在的图表组，趋势与数据组保留；
验收把「图表」归入 `skipped` 并标注「⏭ 已按用户要求省略」。
注意：本场景「数据」组 `verify_excludes=[]`，永不可被排除，避免「销售额」等高频词误触发。

## 运行

```bash
python -m synergyos.cli --scenario biz --task "分析上半年销售额并生成可视化图表" --report
```
