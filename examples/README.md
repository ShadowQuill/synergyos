# 示例集 · Examples

本目录收录 SynergyOS 在 `dev` 应用场景（软件研发）下产出的可运行示例，用于演示「左脑规划 → 右脑观察 → 反思自愈 → 落盘交付」全链路。

每个示例是一个独立子目录，通常包含：

| 文件 | 说明 |
|------|------|
| `README.txt` | 任务背景与需求说明 |
| `plan.json` | 左脑产出的实现规划（结构化步骤） |
| `solution.py` | 生成的实现代码 |
| `tests.py` | 对应的单元测试（dev 场景会真实 `pytest` 跑通） |

## 现有示例

### 1. 实现去重并保持原顺序的函数（`实现去重并保持原顺序的函数/`）

- **任务**：实现一个函数，对输入列表去重，并保持元素首次出现的原有顺序。
- **规划**（`plan.json`）：包含签名、输入输出契约、边界情况（空列表、全重复、含 None）。
- **实现**（`solution.py`）：`dedupe(seq)` 基于 `dict.fromkeys` / 集合维持顺序。
- **测试**（`tests.py`）：覆盖 `[1,2,2,3]→[1,2,3]`、`['a','a','b']→['a','b']`、空列表、保持顺序等用例，全部通过。

运行该示例的测试：

```bash
cd 实现去重并保持原顺序的函数
python -m pytest tests.py -q
```

## 如何新增示例

1. 新建子目录（建议用任务主题的简短中文目录名）。
2. 放入 `README.txt` / `plan.json` / `solution.py` / `tests.py`（文件名可按需调整）。
3. 确保 `tests.py` 可用 `pytest` 独立跑通——这是 `dev` 场景「反思自愈」验证的黄金标准。

> 这些示例是研发场景的**落盘产出样例**，也可作为回归 fixture。运行产物（`out_*/`、`reports_*/`）已被 `.gitignore` 忽略，请勿提交。
