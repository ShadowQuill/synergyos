# 示例集 · Examples

本目录收录 SynergyOS 各应用场景下产出的示例，用于演示「左脑规划 → 右脑观察 → 反思自愈 → 落盘交付」全链路，以及核心能力**「用户显式排除要素时诚实省略」**、**多智能体协作**、**智能体调工具**、**软学习闭环（越用越聪明）**。

每个场景一个子目录，覆盖其 `verify_markers` 必备要素；README 中说明该场景的验收标准与「排除要素」行为。

## 现有示例

### 1. 实现去重并保持原顺序的函数（`实现去重并保持原顺序的函数/`）— dev

- **任务**：实现一个函数，对输入列表去重，并保持元素首次出现的原有顺序。
- **规划**（`plan.json`）：包含签名、输入输出契约、边界情况（空列表、全重复、含 None）。
- **实现**（`solution.py`）：`dedupe(seq)` 基于 `dict.fromkeys` / 集合维持顺序。
- **测试**（`tests.py`）：覆盖 `[1,2,2,3]→[1,2,3]`、`['a','a','b']→['a','b']`、空列表、保持顺序等用例，全部通过。

运行该示例的测试：

```bash
cd 实现去重并保持原顺序的函数
python -m pytest tests.py -q
```

### 2. 周报生成示例（`paas/周报生成示例/`）— paas

- **任务**：整理本周工作并生成一份结构化周报。
- **产出**（`周报.md`）：覆盖本周完成 / 进行中 / 风险与阻塞 / 下周重点四段。
- **排除演示**：若任务写成「不用写风险和下周计划」，该两组归入 `skipped` 并诚实标注省略。

### 3. 销售可视化示例（`biz/销售可视化示例/`）— biz

- **任务**：分析上半年销售额并生成可视化图表。
- **产出**（`销售分析.md`）：数据 → 趋势 → 图表三段。
- **排除演示**：「不用画图」只省略图表组，趋势/数据保留；「数据」组永不可被排除。

### 4. 代码评审示例（`code-review/代码评审示例/`）— code-review

- **任务**：审查这段去重函数并指出问题与改进。
- **产出**（`评审报告.md`）：问题清单 → 严重性 → 建议 → 结论四段。
- **排除演示**：「只列出问题并给严重性」把建议/结论归入 `skipped`；「不用给结论」只省略结论组。

### 5. 销售洞察示例（`data-analysis/销售洞察示例/`）— data-analysis

- **任务**：分析上半年销售额并给出关键结论。
- **产出**（`洞察报告.md`）：数据 → 趋势 → 结论（按用户「不用画图」省略图表）。
- **排除演示**：「不用画图」只省略图表组，数据/趋势/结论保留；「数据」组永不可被排除。

### 6. 新能力演示（`99-tools/`）— 工具接口 & 语义记忆 & 软学习（离线可跑）

- 演示改进报告 P0 / P1 新增能力：MCP 风格工具接口（`mcp_tools_demo.py`，含真实沙箱与可开关联网）、语义记忆层（`semantic_memory_demo.py`）、量化评测（`python3 -m synergyos.eval`），均零依赖、无需 API Key。
- 软学习闭环（经验库 + 失败模式库 + few-shot + 权重持久化）用 CLI 直接体验见 `EVIDENCE.md`。
- 详见 [`99-tools/README.md`](./99-tools/README.md)。

## 如何新增示例

1. 在对应场景目录下新建子目录（建议用任务主题的简短中文目录名）。
2. 放入 `README.md`（说明场景/任务/验收/排除行为）+ 该场景的产出文件。
3. `dev` 场景请确保 `tests.py` 可用 `pytest` 独立跑通——这是「反思自愈」验证的黄金标准。

> 这些示例是各场景的**落盘产出样例**，也可作为回归 fixture。运行产物（`out_*/`、`reports_*/`）已被 `.gitignore` 忽略，请勿提交。
