# 示例：个人助理 · 周报生成（paas）

- **场景**：`paas`
- **任务**：整理本周工作并生成一份结构化周报
- **验收要素（verify_markers）**：本周完成 / 进行中 / 风险与阻塞 / 下周重点

## 这个示例展示什么

`周报.md` 是 paas 场景 mock 引擎产出的周报。它覆盖了 4 个必备要素组，
因此结构化验收会判定 `passed=True, fixes=0`。

## 用户排除要素时（诚实省略）

若用户任务写成「生成本周周报，不用写风险和下周计划」，
验收会命中强排除信号「不用」，把「风险」与「下周重点」两组归入 `skipped`，
并在报告中诚实标注「⏭ 已按用户要求省略」，而非强行补全。
（真实验证见仓库根 `EVIDENCE_EXCLUDE.md`。）

## 运行

```bash
python -m synergyos.cli --scenario paas --task "整理本周工作并生成一份结构化周报" --report
```
