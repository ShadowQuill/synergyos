# 示例：软件研发 · 代码评审（code-review）

- **场景**：`code-review`
- **任务**：审查这段去重函数并指出问题与改进
- **验收要素（verify_markers）**：问题清单 · 严重性 · 建议 · 结论

## 这个示例展示什么

`评审报告.md` 是 code-review 场景 mock 引擎产出的评审意见，覆盖
「问题 → 严重性 → 建议 → 结论」四段，结构化验收判定 `passed=True`。

## 用户排除要素时（诚实省略）

若用户任务写成「只列出问题并给严重性，不用给修复建议」，
限定包含信号「只列出」点名问题/严重性，其余（建议/结论）归入 `skipped`；
若写成「不用给结论」，则强排除只作用到结论组，建议组保留。
验收据此诚实标注「⏭ 已按用户要求省略」。

## 运行

```bash
python -m synergyos.cli --scenario code-review --task "审查这段去重函数并指出问题与改进" --report
```
