运行方式

开箱即跑（Mock 引擎）

python3 -m synergyos.cli --auto --task "你的任务"
无需任何 API Key。

接入真实大模型

export OPENAI_API_KEY=sk-...
引擎自动切换为 OpenAI 兼容接口，代码零改动。

交互式冷启动

python3 -m synergyos.cli
终端会问 5 道选择题建立你的画像。
